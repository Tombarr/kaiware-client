# Kaiware Client

Originally developed by [Garrett Downs](https://github.com/NotSpecCo/kaiware-test-client). This version runs on GitHub Pages.

## Access

Run [Kaiware](https://github.com/NotSpecCo/kaiware) on your desktop. Open the client from the browser on [https://tombarr.github.io/kaiware-client/](https://tombarr.github.io/kaiware-client/), with your IP address and port (default `3000`) in the query parameters.

- `address`: local IP address, default: `192.168.0.1`
- `port`: local port, default: `3000`
- `deviceName`: device name, default: `My Device`

### Why not serve the client locally?

It's a pain to set up local HTTPS with valid certificates, and running on HTTP will result in, "This operation is insecure."
